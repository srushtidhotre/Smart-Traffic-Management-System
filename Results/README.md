# Results

This folder contains the output files generated by the Smart Traffic Management System during traffic video analysis.

## 📊 Result Files

### 1. dashboard_analysis.csv

This file contains frame-by-frame traffic analytics generated by the dashboard.

It includes information such as:

- Frame number
- Number of detected vehicles
- Average vehicle speed
- Number of queued vehicles
- Congestion score
- Number of traffic violations
- Priority lane
- Lane-wise vehicle counts
- Density score
- Traffic/congestion level

The file can be opened using Microsoft Excel, Google Sheets, or any other CSV-compatible application.

---

### 2. traffic_violations.csv

This file contains the traffic violations detected during video analysis.

It records information such as:

- Vehicle/Track ID
- Violation type
- Frame number
- Violation description

The file provides a structured record of detected traffic violations and can be used for further analysis.

---

## 📈 Purpose of the Results

The generated results demonstrate the system's ability to:

- Monitor traffic conditions frame by frame
- Count and track vehicles
- Estimate traffic density
- Measure average vehicle speed
- Estimate vehicle queues
- Calculate congestion levels
- Identify priority lanes
- Detect traffic violations
- Generate structured traffic reports

These results can also be used for further statistical analysis and visualization.

---

## ⚠️ Note

The CSV files in this folder are sample outputs generated during testing of the system.

New result files can be generated automatically by running the Streamlit dashboard and performing traffic analysis.
